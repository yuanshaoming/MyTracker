# KalmanBoxTracker（Task 05）

`KalmanBoxTracker` 是内部固定步长框状态估计器，不分配业务 ID，也不管理轨迹生命周期或动态时间步长。

## 状态与观测

状态向量为：

```text
x = [cx, cy, s, r, vx, vy, vs]^T
```

`cx`、`cy` 为框中心，`s` 为面积，`r` 为宽高比，后三项是每帧速度。观测向量为：

```text
z = [cx, cy, s, r]^T
```

`F` 为单位矩阵，并设置 `F(0,4)=F(1,5)=F(2,6)=1`，因此固定 `dt=1`。`H` 选择状态的前四个分量。

## 初始协方差与噪声

初始协方差 `P` 的对角线为 `[10, 10, 10, 10, 100, 100, 100]`：初始框观测的不确定性低于未观测速度。观测噪声 `R` 为单位矩阵；过程噪声 `Q` 的对角线为 `[1, 1, 1, 1, 0.01, 0.01, 0.01]`。

这些值是固定步长基础实现的初始选择，只经本机合成单元测试验证，不代表现场或设备调参结果。

## 数值与失败状态

更新通过 LDLT 分解求解创新协方差，不直接求逆。构造参数必须能转换为有效 `BBox`，否则抛出 `std::invalid_argument`。无效观测会使 `update()` 返回 `false` 且不改变状态。

每次 `predict()` 和成功观测更新后，状态都必须能转换为有限、正面积且正宽高比的框。若预测面积非正、状态非有限或无法生成有效框，实例进入不可用状态，当前调用返回 `false`，之后 `estimate()` 返回空值，且不能通过后续 `update()` 恢复。
